Before and after merging

Does it translate subtitles?

No. It only matches two existing subtitle files by time.

When are cues matched automatically?

Only when timeline IoU is at least 0.5 and each cue has a unique mutual best match.

Can I download while matches are ambiguous?

No. Pair each ambiguous cue or explicitly keep it separate before an output is created. If a candidate replaces an automatic pair, the confirmation names that pair; canceling preserves the existing result.

Can I manually pair cues below 0.5 IoU?

Yes, after reviewing the exact ratio and warning. Canceling leaves existing matches unchanged.

Can I keep an automatic match as separate cues?

Yes. The confirmation names the released cue; canceling keeps the original match.

Are unmatched cues discarded?

No. They stay in the output by default; excluding one requires an explicit choice and confirmation. Excluded cues can be restored.

Which subtitle files are supported?

This release defines a strict UTF-8 SRT profile and does not claim support for every SRT variant or player. It accepts LF, CRLF, CR, and one BOM; cue numbers start at 1 consecutively, timecodes have no extra settings, and each cue has nonblank text.

What if too many subtitle cues overlap?

More than 50,000 eligible candidate pairs stops the whole job with a clear prompt to shorten the subtitle segments; no partial result is offered.

Are my files uploaded?

No. Files are processed in local memory without upload, AI, or conversion. Switching language loses the current job. Downloaded files remain under your browser’s and operating system’s control.
